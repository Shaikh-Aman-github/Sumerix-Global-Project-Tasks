# Project Overview

## Cyber Security & Ethical Hacking Internship — Task 1

**Task:** Task 1  
**Domain:** Cyber Security & Ethical Hacking  
**Project:** Secure Network Asset Inventory & System Information Scanner

---

## 1. Introduction

Task 1 establishes the cybersecurity, Linux, networking, virtualization, and programming foundations required for further ethical hacking and penetration testing activities.

The task focuses on building a secure cybersecurity laboratory, understanding Linux administration and networking fundamentals, and developing a basic Python-based security utility.

The practical environment uses Kali Linux running inside a virtual machine. The project also introduces Git and GitHub for professional project organization and version control.

---

## 2. Task Objectives

The main objectives of Task 1 are:

- Understand fundamental cybersecurity concepts.
- Understand ethical hacking principles and responsibilities.
- Build a secure and isolated cybersecurity laboratory.
- Install and configure Kali Linux.
- Understand virtualization and virtual machines.
- Learn Linux filesystem navigation and terminal commands.
- Understand users, groups, permissions, and privilege management.
- Learn networking fundamentals.
- Understand IPv4 addressing and subnet basics.
- Understand the OSI and TCP/IP models.
- Understand common networking protocols and ports.
- Use Git and GitHub for project version control.
- Develop a Python-based system and network information utility.
- Generate and save a structured system inventory report.

---

## 3. Cybersecurity Lab Environment

The cybersecurity laboratory is designed around a host operating system and a Kali Linux virtual machine.
